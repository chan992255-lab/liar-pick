# 🕵️ 라이어픽 (LiarPick)

폰 하나로 친구들과 바로 즐기는 파티 게임 웹앱입니다.

## 게임

- **라이어 게임** (3~12명): 일반 모드 / 바보 모드, 9개 카테고리 제시어, 가림 카드로 한 명씩 역할 확인, 토론 타이머(1~5분·일시정지·+30초), 지목 투표·비밀 투표, 라이어의 마지막 역전 기회, 누적 점수판.
- **마피아 게임** (4~12명): 인원별 마피아·경찰·의사 자동 추천 + 직접 조절, 밤 페이즈(마피아 지목·경찰 조사·의사 보호·시민 더미 화면), 아침 결과, 낮 토론·처형 투표, 승리 조건 자동 판정.

## 기술

- React 18 + TypeScript + Vite + Tailwind CSS
- Web Audio API 효과음(켜고 끄기 지원), localStorage 누적 점수 저장
- 모바일 390×844 기준 PWA (홈 화면에 추가 가능)

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist)
```
