# 🕵️ 라이어픽 (LiarPick)

폰 하나로 친구들과 바로 즐기는 파티 게임 웹앱입니다. 로그인하면 온라인으로 모르는 사람과도 할 수 있어요.

## 게임

- **라이어 게임** (3~12명): 일반 모드 / 바보 모드, 9개 카테고리 제시어, 가림 카드로 한 명씩 역할 확인, 토론 타이머(1~5분·일시정지·+30초), 지목 투표·비밀 투표, 라이어의 마지막 역전 기회, 누적 점수판.
- **마피아 게임** (4~12명): 인원별 마피아·경찰·의사 자동 추천 + 직접 조절, 밤 페이즈(마피아 지목·경찰 조사·의사 보호·시민 더미 화면), 아침 결과, 낮 토론·처형 투표, 승리 조건 자동 판정.

## 두 가지 플레이 방식

1. **📱 폰 하나로 같이하기** — 로그인 없이 기존 오프라인 모드. 점수는 이 기기에 저장(localStorage).
2. **🌐 온라인 매칭** — 이메일·비밀번호·닉네임으로 가입/로그인 후,
   - 빠른 매칭(대기 중인 공개 방 자동 입장·없으면 새로 생성),
   - 공개 방 목록 / 6자리 방 코드,
   - 실시간 대기실(참가자·준비·방 설정·채팅),
   - 각자 폰에 자기 역할·제시어만 표시되는 실시간 게임 진행,
   - 판수·승리·점수 전적 저장.

## 기술

- React 18 + TypeScript + Vite + Tailwind CSS
- Supabase(Auth · Postgres · RLS · Realtime · RPC)로 온라인 매칭 — 스키마는 `supabase/schema.sql`
- Web Audio API 효과음(켜고 끄기 지원), localStorage 누적 점수 저장(오프라인)
- 모바일 390×844 기준 PWA (홈 화면에 추가 가능)

## 실행

```bash
npm install
npm run dev      # 개발 서버 ( .env.local 에 VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY )
npm run build    # 프로덕션 빌드 (dist)
```

배포: Vercel (`vercel deploy --prod`) · https://liar-pick.vercel.app

> 한 기기에서 계정 두 개를 동시에 테스트하려면 `?slot=b`처럼 슬롯을 붙이면
> 그 슬롯 전용 세션 저장소를 써서 탭마다 다른 계정으로 접속할 수 있습니다.
